# Руководство пользователя программного комплекса
**Проект 2039: «Механизмы цифрового забвения»**

Данный документ предназначен для конечных пользователей, операторов и аналитиков (data scientists), работающих с комплексом по исследованию Machine Unlearning на базе архитектуры SISA (Sharded, Isolated, Sliced, Aggregated).

## 1. Состав комплекса
Программный прототип состоит из двух ключевых подсистем:
1. **Генератор синтетических данных (`synthetic_data_generator`)**: Создает статистически достоверные табличные датасеты с преднастроенными распределениями признаков и связями.
2. **Система Machine Unlearning (`unlearning_system`)**: Управляет процессами обучения, маршрутизации пользователей по шардам (SISA), удалением данных и пересчетом метрик.

Дополнительно в корне проекта доступна интерактивная консоль **`panel.py`** для работы в REPL-режиме, а также веб-интерфейс (`web_app.py`) для генерации демо-данных.

---

## 2. Быстрый старт (CLI)

Для полного прохождения цикла по ТЗ (Генерация -> Обучение -> Забвение -> Оценка) необходимо выполнить следующие шаги в терминале:

### Шаг 1: Генерация набора данных
```bash
cd synthetic_data_generator
python main.py generate --count 5000 --seed 42
```
В консоли отобразится успешный лог. Сгенерированный файл будет сохранен в пути: `data/synthetic_dataset_*.csv`.

### Шаг 2: Первичное обучение (SISA)
```bash
cd ../unlearning_system
python cli.py train \
    --config configs/default.yaml \
    --data ../synthetic_data_generator/data/synthetic_dataset_*.csv
```
Команда инициирует папку эксперимента (`runs_tmp/...`), разобьет данные на шарды и обучит независимые мини-модели. В логах консоли будут выведены начальные метрики (Accuracy, Precision, Recall, F1, AUC).

### Шаг 3: Удаление персональных данных (Unlearning)
Право на забвение по запросу конкретных пользователей.
```bash
python cli.py unlearn \
    --config configs/default.yaml \
    --data ../synthetic_data_generator/data/synthetic_dataset_*.csv \
    --user-ids U-000001 U-000005 U-000012 \
    --reason "user_request"
```
Система определит, в каких шардах находятся пользователи, переобучит только эти изолированные шарды и пересчитает метрики ($\Delta$ Accuracy, $\Delta$ F1).

### Шаг 4: Формирование отчета
```bash
python cli.py report --run runs/<run_id>
```
На экран будет выведен агрегированный JSON с историей событий: от первоначального обучения до всех дельт метрик после "цифрового забвения".

## 3. Работа через интерактивную панель (`panel.py`)
Чтобы не прописывать пути вручную, используйте `panel.py` — она сохраняет состояние в оперативной памяти.

```bash
python panel.py
```

Откроется меню, в котором можно использовать команды:
* `generate_data` — запустить генератор.
* `train` — обучить ансамбль на сгенерированных данных.
* `unlearn_id <ID>` — удалить строку с конкретным ID пользователя.
* `status` — просмотреть показатели качества (Accuracy, F1, AUC и т.д.).
* `exit` — завершить работу сессии.

## 4. Веб-интерфейс и стандартизация ответов
Для запуска локального демо-генератора через браузер:
```bash
cd synthetic_data_generator
python web_app.py
```
* Перейдите по адресу: `http://localhost:5000`
* API стандартизировано. В случае ошибки валидации параметров система возвращает JSON формата: `{"success": False, "error": "Описание ошибки"}`.
