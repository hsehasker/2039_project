# Документация разработчика
**Проект 2039: «Механизмы цифрового забвения»**

## 1. Архитектура программного комплекса
Комплекс состоит из двух независимых python-пакетов, которые интегрируются на уровне передачи данных (файлы `.csv`) и через интерактивную консоль `panel.py`:

* `synthetic_data_generator/` — подсистема подготовки контролируемых данных.
* `unlearning_system/` — ядро машинного "разобучения" (алгоритм SISA).

Кодовая база полностью соответствует требованиям ТЗ и реализована с использованием чистого ООП-подхода, стандартизированного логирования и строгой верификации по метрикам.

---

## 2. Подсистема генерации данных (Synthetic Data Generator)

Находится в `synthetic_data_generator/generator/`.
* **Извлечение и распределения (`distributions.py` / `correlations.py`)**: Отвечают за генерацию статистически правильных признаков (Нормальное, Логнормальное, Экспоненциальное).
* **Разметка таргета (`labeler.py`)**: Имеет два поддерживаемых режима (rules и probabilistic). Метки определяются на основе признаков (например, отсутствие `consent_given` повышает весомость таргета).
* **Запуск и API**: `main.py` предоставляет CLI-интерфейс, а `web_app.py` — Flask API. Все ошибочные ответы `web_app` строго следуют формату: `{"success": False, "error": ...}`.

---

## 3. Подсистема SISA Machine Unlearning
Реализует концепцию изолированного обучения (Sharded, Isolated, Sliced, Aggregated) — в реализации проекта используются только Шарды (Shards). Код находится в `unlearning_system/ml/`.

### 3.1. Фабрика моделей и поддержка алгоритмов
Согласно ТЗ поддерживаются строго 3 типа математических алгоритмов классификации:
1. **Logistic Regression (PyTorch)** — реализована в `logreg.py` как полноценный `nn.Module`.
2. **Random Forest (Scikit-Learn)** — обертка в `rf.py`.
3. **Decision Tree (Scikit-Learn)** — обертка в `dt.py` (классификатор `DecisionTreeClassifier`).
*(Модели SVM и Gradient Boosting не поддерживаются и целенаправленно исключены из контура)*.

### 3.2. Алгоритм разобучения (Unlearner)
Механизм управления шардами реализован в файлах `shards.py` и `sisa.py`.
* При инициализации датасет разбивается на $K$ батчей (шардов). Для каждой строки запоминается ее принадлежность к шарду (детерминировано по `user_id`).
* В методе `unlearn()` (`unlearning.py`) создается запрос `UnlearnRequest`.
* Контроллер SISA вычисляет затронутые шарды и **переобучает только их**, минуя полное ресурсоемкое переобучение, что дает экономию вычислительных затрат.

### 3.3. Расчет метрик (Metrics)
Осуществляется модулем `metrics.py`:
Высчитывается структура: `Accuracy`, `Precision`, `Recall`, `F1`, `AUC`, `MSE`.
**Важно:** Математика F1-меры реализована академически верно через `Precision` и `Recall`: $$F1 = 2 \cdot \frac{Precision \times Recall}{Precision + Recall}$$.
После каждого факта удаления система вычисляет дельту ($\Delta$) показателей "До / После" ($metrics\_after - metrics\_before$) и сохраняет результат в JSON Lines файл.

## 4. Логирование и тесты

* **Логирование**: С целью аудита вместо `print()` везде используется штатный модуль `logging`. История экспериментов (параметры, seed, deltas) сохраняется в папках `runs/<run_id>/manifest.yaml` и `events.jsonl`.
* **Модульное и интеграционное тестирование**: Обеспечивается 49-ю тестами на базе `pytest`.
  * *45 unit-тестов* (`synthetic_data_generator/tests`) — покрывают математику распределений.
  * *4 end-to-end теста* (`unlearning_system/tests/test_smoke.py`) — валидируют корректность алгоритма SISA по удалению шардов и пересчету $\Delta$метрик.

Контроль версий и запуск:
```bash
# Тесты генератора
PYTHONPATH=synthetic_data_generator pytest synthetic_data_generator/tests -v
# Smoke тесты движка ML
PYTHONPATH=unlearning_system pytest unlearning_system/tests -v
```
